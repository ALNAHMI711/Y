# ثقافة وطن للمستلزمات العسكرية — منصة وتطبيق

تنفيذ أولي (MVP) لوثيقة التوصيف: خادم Node.js بلا اعتماديات خارجية (HTTP + SQLite المدمجين في Node 22.13+) وتطبيق ويب PWA بالعربية (RTL) يعمل بدون إنترنت.

## التشغيل

```bash
cd server
npm test                       # 6 اختبارات شاملة
ADMIN_PHONE=967700000001 DEV_OTP=1 npm start   # http://localhost:3000
```

| متغير | الوظيفة |
|---|---|
| `ADMIN_PHONE` | رقم أول مدير (يصبح admin عند أول تسجيل) |
| `DEV_OTP=1` | يُرجع رمز التحقق في الاستجابة للتجربة فقط — **لا يُفعّل في الإنتاج** |
| `INGEST_KEY` | مفتاح تطبيق/جهاز يمرّر رسائل المحافظ إلى `/api/sms/ingest` |
| `SUPPORT_PHONE` | رقم دعم واتساب لإشعارات التحويلات غير المطابقة |
| `ENC_KEY` / `APP_SECRET` | مفاتيح التشفير والتوقيع؛ تُولَّد تلقائياً في `server/data/` إن لم تُحدَّد |
| `DATA_DIR`, `PORT` | مسار البيانات والمنفذ |

عند أول تشغيل: سجّل الدخول بـ`ADMIN_PHONE`، ثم من «الإدارة ← الخزنة ← إعداد أولي» عيّن الرمزين (10 أرقام لكل منهما).

## ما لم يُنفَّذ عمداً

- **نشر المتاجر وبناء APK**: يتطلب حسابات Apple/Google وخط بناء (مثل Capacitor/EAS). التطبيق حالياً PWA قابل للتثبيت.
- **الأتمتة الخفية لتجاوز الحظر (RPA / Headless)**: تخالف شروط المنصات وتعرّض الحسابات للإغلاق؛ استُبدلت بواجهات API الرسمية فقط.
- **تحويل الأموال الفعلي للتجار**: يُسجَّل السحب بحالة `queued`؛ التنفيذ يتم عبر المحفظة/البنك خارج النظام.
- **مبالغ المتاجر (أبل/بلي)** تُدخل يدوياً في الخزنة (لا توجد واجهة آلية).

## ملاحظات أمنية

- بطاقات الهوية والعقود مشفّرة في القاعدة (AES-256-GCM)؛ احفظ `ENC_KEY` نسخة احتياطية، فقدانه يعني فقدان البيانات المشفرة.
- النظام ليس «بدون أخطاء» — اختباراتك الميدانية على مسار الدفع والضمان ضرورية قبل التشغيل الفعلي بأموال حقيقية.
- عيّن `DEV_OTP` غير مفعّل، وضع الخادم خلف HTTPS.
